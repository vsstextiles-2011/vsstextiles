# Category Images (Shop by Category banner)

This folder holds the 4 big banner tiles shown in the homepage's
"Shop by Category" section and reused in the hero slider — Men,
Women, Boys, Girls.

To change a photo, just **replace the file with your own image,
keeping the exact same filename**. No code changes needed.

Recommended: wide banner photos, at least 1600x500px, JPG or PNG.

## main/ — the 4 big banner tiles
- `men.jpg`
- `women.jpg`
- `boys.jpg`
- `girls.jpg`

Looking for the smaller per-item tile photos used in the homepage
"Men's / Women's / Boys' / Girls' Collection" grid sections (T-Shirts,
Shorts, Briefs, etc.)? Those live in a separate folder —
`public/images/collections/` — on purpose, so the two sections never
overwrite each other. See `public/images/collections/README.md`.

Looking for the big hero slider photos at the very top of the homepage
(New Arrival, Men's Edit, Women's Edit, etc.)? Those live in
`public/images/hero/` — also on purpose. See
`public/images/hero/README.md`.

Every file currently in this folder is a placeholder image labeled with
the category name so the site displays correctly out of the box. Swap
them out whenever you're ready — the site will pick up the new photo
automatically the next time the page loads.
